# Healthcare Analytics Dashboard

## 📊 Project Overview

The **Healthcare Analytics Dashboard** is a data analytics project designed to analyze healthcare data and provide meaningful insights into patient demographics, hospital performance, treatment trends, and key healthcare metrics.

The dashboard transforms raw healthcare data into interactive visualizations and KPIs, helping users understand patterns and trends in healthcare operations.

## 🎯 Objectives

* Analyze patient demographics and healthcare trends.
* Monitor important healthcare KPIs.
* Analyze patient distribution by age and gender.
* Identify department-wise patient trends.
* Analyze hospital and treatment-related performance.
* Create an interactive dashboard for better data-driven decision-making.

## 🛠️ Tools & Technologies

* **Tableau** – Dashboard development and data visualization
* **SQL** – Data querying and analysis
* **Microsoft Excel / CSV** – Data preparation and storage
* **Data Cleaning** – Handling missing and inconsistent data
* **Data Visualization** – Charts, graphs, KPIs, and interactive filters

## 📌 Key KPIs

The dashboard includes important healthcare metrics such as:

* Total Patients
* Male Patients
* Female Patients
* Average Patient Age
* Department-wise Patients
* Treatment Trends
* Patient Distribution
* Hospital Performance

## 📈 Dashboard Features

* Interactive KPI cards
* Patient demographic analysis
* Age-wise patient distribution
* Gender-wise patient analysis
* Department-wise analysis
* Treatment and healthcare trend analysis
* Interactive filters
* Charts and visualizations
* Data-driven insights

## 🔍 Key Insights

The dashboard helps identify:

* Patient distribution across different age groups.
* Gender-wise patient patterns.
* Departments with higher patient volumes.
* Treatment and healthcare service trends.
* Important patterns that can support healthcare decision-making.
